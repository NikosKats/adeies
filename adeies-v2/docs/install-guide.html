Οδηγός Εγκατάστασης από Μηδέν
Έκδοση 2.0  ·  Windows · macOS · Linux
Πριν ξεκινήσετε: Αποφασίστε ποιος υπολογιστής θα είναι ο server της βάσης δεδομένων. Αν το χρησιμοποιεί μόνο ένας, αυτός ο ίδιος PC είναι ο server. Αν υπάρχουν πολλοί χρήστες στο LAN, εγκαταστήστε τη βάση σε έναν μόνο PC και συνδέστε τους υπόλοιπους μέσω IP.
🪟 Windows 10 / 11
  1. 1
    Κατεβάστε τα αρχεία από το GitHub repository:
    Μεταβείτε στον φάκελο adeies-v2/scripts/ και κατεβάστε το setup-db-windows.ps1.
    Επίσης κατεβάστε τον installer Adeies-Setup.exe από τον φάκελο dist-installer/ (αν έχει ήδη γίνει build) ή κάντε build μόνοι σας (δείτε παρακάτω).
  2. 2
    Εκτελέστε το script ρύθμισης βάσης δεδομένων:
    Δεξί κλικ στο αρχείο setup-db-windows.ps1 → "Εκτέλεση με PowerShell ως Διαχειριστής".
    Το script: (α) εγκαθιστά αυτόματα PostgreSQL 16 μέσω winget αν δεν υπάρχει, (β) δημιουργεί τον χρήστη adeies και τη βάση δεδομένων, (γ) ρυθμίζει την αυτόματη εκκίνηση PostgreSQL με τα Windows.
    Όταν ζητηθεί, εισάγετε τον κωδικό του postgres superuser (αυτόν που ορίσατε κατά την εγκατάσταση PostgreSQL).
  3. 3
    Εγκαταστήστε την εφαρμογή:
    Εκτελέστε το Adeies-Setup.exe → Επόμενο → Επόμενο → Τέλος.
  4. 4
    Ανοίξτε το Adeies από το shortcut στο Desktop.
    Μεταβείτε στις Ρυθμίσεις και επαληθεύστε τα παρακάτω στοιχεία:
    ΠεδίοΤιμή
    Hostlocalhost
    Port5432
    Databaseadeies
    Usernameadeies
    Passwordadeies
    Κλικ Δοκιμή Σύνδεσης — πρέπει να εμφανιστεί πράσινο "OK". Κλικ Αποθήκευση.
  5. 5
    Πρώτη σύνδεση: Username admin · Password admin123.
    Αλλάξτε τον κωδικό αμέσως: Χρήστες → εικονίδιο κλειδιού → Νέος Κωδικός.
🍎 macOS (Intel & Apple Silicon)
  1. 1
    Κατεβάστε τα αρχεία από το GitHub:
    Κατεβάστε το setup-db-mac.sh από adeies-v2/scripts/ και το Adeies.dmg από dist-installer/.
  2. 2
    Ανοίξτε το Terminal (Launchpad → Terminal ή Spotlight: Terminal) και εκτελέστε:
    bash ~/Downloads/setup-db-mac.sh
    Το script εγκαθιστά αυτόματα Homebrew (αν δεν υπάρχει) και PostgreSQL 16, ξεκινά την υπηρεσία, και δημιουργεί τη βάση δεδομένων.
  3. 3
    Εγκαταστήστε την εφαρμογή:
    Ανοίξτε το Adeies.dmg και σύρτε το εικονίδιο Adeies στον φάκελο Applications.
  4. 4
    Ανοίξτε το Adeies από το Launchpad ή το Spotlight.
    Αν εμφανιστεί "Δεν είναι δυνατό το άνοιγμα": Ρυθμίσεις Συστήματος → Απόρρητο & Ασφάλεια → "Άνοιγμα Ούτως ή Άλλως".
  5. 5
    Ρυθμίσεις σύνδεσης: Ίδια με Windows (localhost, 5432, adeies/adeies/adeies).
    Δοκιμή Σύνδεσης → Αποθήκευση → Σύνδεση: admin / admin123.
🐧 Linux (Ubuntu / Debian / Fedora)
  1. 1
    Εγκαταστήστε PostgreSQL:
    # Ubuntu / Debian sudo apt update && sudo apt install -y postgresql sudo systemctl enable --now postgresql # Fedora / RHEL sudo dnf install -y postgresql-server postgresql sudo postgresql-setup --initdb sudo systemctl enable --now postgresql
  2. 2
    Δημιουργήστε τον χρήστη και τη βάση δεδομένων:
    sudo -u postgres psql -c "CREATE USER adeies WITH PASSWORD 'adeies';" sudo -u postgres psql -c "CREATE DATABASE adeies OWNER adeies;" sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE adeies TO adeies;"
  3. 3
    Κατεβάστε το Adeies.AppImage και εκτελέστε:
    chmod +x Adeies.AppImage ./Adeies.AppImage --no-sandbox
  4. 4
    Ρυθμίσεις → εισάγετε τα στοιχεία → Δοκιμή Σύνδεσης → Αποθήκευση.
    Σύνδεση: admin / admin123.
🌐 Πολλαπλοί Χρήστες στο Ίδιο Δίκτυο (LAN)
Εγκαταστήστε PostgreSQL μόνο σε έναν PC (αυτός γίνεται ο server). Σε όλους τους υπόλοιπους υπολογιστές εγκαταστήστε μόνο την εφαρμογή Adeies και στις Ρυθμίσεις βάλτε την IP του server.
  1. 1
    Βρείτε την IP του server:
    · Windows: ανοίξτε CMD → πληκτρολογήστε ipconfig → "IPv4 Address"
    · macOS: Ρυθμίσεις Συστήματος → Wi-Fi / Ethernet → IP Address
    · Linux: ip addr show → ψάξτε για 192.168.x.x
  2. 2
    Σε κάθε client PC, στις Ρυθμίσεις του Adeies, βάλτε:
    Host: 192.168.1.10 (ή ό,τι IP έχει ο server σας)
  3. 3
    Windows Firewall (στον server): Επιτρέψτε εισερχόμενες συνδέσεις στη θύρα 5432.
    Πίνακας Ελέγχου → Windows Defender Firewall → Προηγμένες Ρυθμίσεις → Κανόνες Εισερχόμενων → Νέος Κανόνας → Θύρα 5432 TCP → Να επιτρέπεται.

📦 Μετάπτωση από Παλαιά Εφαρμογή Java (SQLite)

Αν διαθέτετε αρχείο adeies.db από την παλιά εφαρμογή:

  1. 1
    Εγκαταστήστε Node.js 20+ από nodejs.org και κατεβάστε τον πηγαίο κώδικα.
  2. 2
    Εκτελέστε το migration script:
    # macOS / Linux SQLITE_PATH=/path/to/adeies.db \ DATABASE_URL=postgresql://adeies:adeies@localhost:5432/adeies \ npm run migrate:sqlite # Windows PowerShell $env:SQLITE_PATH="C:\path\to\adeies.db" $env:DATABASE_URL="postgresql://adeies:adeies@localhost:5432/adeies" npm run migrate:sqlite
    Μεταφέρει αυτόματα βαπτίσεις, γάμους και πιστοποιητικά στη νέα βάση.

🔧 Συνήθη Προβλήματα
ΠρόβλημαΛύση
"Connection refused" Η PostgreSQL δεν τρέχει. Windows: services.msc → εκκινήστε "postgresql-x64-16". Mac: brew services start postgresql@16
"password authentication failed" Ελέγξτε ότι τρέξατε το setup script και ότι τα στοιχεία στις Ρυθμίσεις είναι σωστά.
macOS: "Δεν μπορεί να ανοιχτεί" Ρυθμίσεις Συστήματος → Απόρρητο & Ασφάλεια → "Άνοιγμα Ούτως ή Άλλως"
Windows: script δεν εκτελείται Βεβαιωθείτε ότι κάνατε δεξί κλικ → "Εκτέλεση ως Διαχειριστής"
Client δεν συνδέεται σε LAN Ελέγξτε το Firewall στον server (θύρα 5432 TCP να επιτρέπεται) και ότι η IP είναι σωστή.
